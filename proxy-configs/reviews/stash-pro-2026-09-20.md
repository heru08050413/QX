## 明确未完成的原生验收

- 没有 iPhone/Stash 原生配置解析器与真实机场：未证明客户端成功导入、订阅可用、真实 failover 时延、内存占用或带宽。
- 脚本隔离测试是 Node.js 模拟指定 API 的形式检查，不是 Stash 内核或真实广告报文测试；不能作为“去广告已彻底”的证据。
- YouTube 上游仅承诺 Surge 测试，完整功能需用户真机核验。Worker 在特定条件下接收目标 URL 与 key/参数；未访问或发送真实数据给 Worker，也未验证其服务端逻辑/可用性。使用前必须读风险说明，自行选择是否启用。
- 空订阅/空组可能原生退化 DIRECT。首次两个境外入口默认 REJECT，只缓解首次误启用，不是运行期间的订阅空集熔断器。
- fallback 保证按健康结果选择候选，不保证迁移既有连接、最快带宽或所有节点失效时仍联网。
- App 过滤只针对明确广告标记和指定接口，不通过清空正文追求表面“全净化”。

用户操作、验收顺序和单层回退详见 [使用说明](../Stash_Pro_README.md)。本次没有触碰任何节点密钥、机场 token、CA 或其他客户端配置。
