# Loon v2.3.0：单客户端修复与验收

日期：2026-09-19。基线：`f2ac77e1e5c6084a67ebf50b7a201cc1f1d86b2e`。
按当次可核对的 Loon 3.5.0 公开版及官方文档审查；手机版本与实际生效配置仍需用户核实。
用户已明确授权本轮检查通过后发布到 main。

只修改 `Loon_V26.00`，新增 Loon 专用测试和本说明。Shadowrocket、Egern、Quantumult X、Stash、共用脚本均不改。

## 改动与取舍

| 项目 | 已实施 | 边界与影响 |
|---|---|---|
| HTTPDNS | 禁用整套 HTTPDNS.Block 插件 | 上游不仅有 Rule，还含微信 newgetdns/getcdndns、微博、知乎相关 URL Rewrite 和支付宝 Map Local；单加 DIRECT 无法取消这些改写。这是确定的配置风险，不是已经证明的本机故障根因。失去该插件的 HTTPDNS 防绕过/隐私控制，可能放行部分跟踪解析 |
| 微信 | 两个 DNS 主机、登录 PCDN 主机本地 DIRECT | 不放开整个 qq.com；hijack-dns 和 DNS 上游原值保留，传统 53 端口劫持不能代替 HTTPDNS/DoH 控制 |
| YouTube | 新建四个专用地区池，使用 Google HTTPS 探针，地区内 120s/300ms、外层 fallback 60s/5000ms | 保留香港→狮城→日本→美国原地区顺序，不再借用 Cloudflare 通用地区池；增加探测开销。gstatic 不是 YouTube 业务端点或带宽检测，不能证明播放正常 |
| YouTube 路由 | API、备用 API、Maasea Worker、googlevideo 本地指定油管视频 | 保持单套 Maasea 三钩子处理链，不额外猜测广告 URL；普通 Google、ChatGPT/AI 默认策略不随之改变 |
| 长连接组 | 四个稳定地区池从 url-test 改 fallback，外层 StableFallback 与内层均 300s/HTTPS | 避免因较低延迟竞速更换出口；fallback 按首个可用项选择，高优先级恢复仍可能回切，不等于粘性会话。首个可用节点也可能吞吐不佳 |
| Gemini | 五个已知专用接口前置到 Gemini；美国筛选器增加 US/USA 字母边界 | 原 Gemini 首选美国保留；排除 Russia/Australia/RUS/AUS 等误匹配。增加常见美国地区名称，但名称不能证明真实出口地区或账号资格 |
| 微博 | 三个精确图片广告主机移至宽泛 DIRECT 前，删除五条被遮蔽的旧拒绝 | 不整域拒绝 sdkapp/biz/bootpreload；SDK 继续交脚本处理。不是新增宽泛去广告黑名单 |
| 误伤 | 删除跨域 `URL-REGEX,"\.log\.",REJECT` | URL 中出现 log 不足以证明是广告；可能少拦一部分遥测，但避免不区分主机/业务的拒绝 |
| MITM | 主文件七个微博/新浪通配符缩成六个 API 主机；补 12306 与支付宝相关主域/子域排除 | 缩小解密面，12306 MITM 去广告不再作为目标；远程插件仍会追加主机，例如微博的 `*.uve.weibo.com`，需在手机有效配置中核对排除优先级 |

订阅占位符、CA/口令、TLS 校验、DNS/DoQ、Host、主分流默认值、其他远程规则/脚本入口均保留。`disconnect-on-policy-change=false`、`udp-fallback-mode=REJECT`、两条订阅的 `block-quic=true` 均保留。

Loon 当前支持 AND/PROTOCOL，旧注释“没有逻辑规则、全局挡 QUIC 是唯一方法”不成立。本轮不贸然恢复全部代理侧 HTTP/3；精细化 QUIC 的 A/B 验证留待真实 UDP 日志。阻断 QUIC 不自动转换协议，TCP 回退取决于应用。

这不是 Loon 原生解析/插件转换测试，不模拟完整远程规则合并或 iPhone 网络。不声称真机去广告、无断流或自动切换已验收。

## 保留风险与待测事项

1. YouTube 模块仍直接引用现有 `.sgmodule`，未新写未经证实的 Loon 参数覆盖语法。上游默认值不证明手机转换后参数正确，缓存及用户保存的参数可能覆盖默认值。需核对三钩子、`blockUpload=true`、Googlevideo MITM；如有转换/JSON 参数错误，提供脱敏日志后再做原生适配，不能仅凭 MITM 图标认定成功。
2. 脚本/模块仍是浮动分支，第三方 Worker 也是外部依赖；本轮没有供应链锁定。YouTube 服务端广告样式、账号实验或客户端升级仍可能绕过现有处理，不能保证彻底去广告。
3. `max-timeout=5000` 是 fallback 判定阈值，不能宣称它覆盖所有网络请求超时。全局 `test-timeout=3` 保持不变，地区 url-test 仍受该设置影响；慢 TLS 握手可能造成假失败。先看真实探测时延，再决定是否修改全局，避免影响全部策略组。
4. 内层 120s 与外层 60s 是探测间隔，不是恢复时限。调度、重试、旧连接、空地区池和全部节点失效都影响结果；已建立 TCP 连接不会无缝迁移。未开启全局断开旧连接，避免牵连微信及 AI 会话。
5. 关闭 HTTPDNS 插件不保证不存在其他规则或插件对同样请求的拦截。大合集和额外手动安装的插件仍可能误伤；保留原广告模块，遇到故障用实际命中记录定位，不能继续无证据叠加拒绝。
6. MITM 缩面是主文件层面的修改，不代表所有外部插件的最终合并范围已经审完。重点确认 12306、支付/登录域未被解密；排除范围内牺牲去广告，优先保安全。

## 手机更新与验收

1. 更新原远程 `Loon_V26.00`，确认文件头出现 `2026-09-19 / v2.3.0`；同时更新插件/规则资源，然后重新加载配置。不要重新生成证书或丢弃原订阅。
2. 仓库订阅为脱敏占位符：刷新前备份手机配置，刷新后确认实际机场订阅和节点仍在。主配置更新不保证本地保存的订阅或手动策略选择自动保留/重置。
3. 确认 HTTPDNS.Block 没有启用的独立副本；油管视频选择 `YT-Auto`，四地区池非空且能探测；Gemini 选择实测有效的美国出口。
4. 确认仅一套 YouTube 增强处理，三钩子均已下载且无脚本/参数错误；隐藏上传打开，PiP/后台开关与 iOS 权限保持启用。
5. 微信测冷启动、消息/图片、语音/视频与 Wi-Fi/蜂窝切换；微博/知乎测正文、图片、登录；12306/支付确认不 MITM。
6. YouTube 分别检查前贴/中插、上传按钮、PiP 和连续播放；建议 30 个视频、3 次各 60 分钟，并观察一次切网/节点异常后的恢复。记录时间、地区/节点、请求错误、脚本错误；不要主动破坏机场或其他服务。
7. Gemini/ChatGPT 测登录、10 轮流式回复与附件。若失败，提供脱敏规则命中、DNS、出口与服务端错误；不要提交 token、Cookie 或 CA 私钥。

回退：只 revert 本轮 Loon 提交并刷新，不 hard reset，不覆盖已发布的小火箭/Egern 或后续其他客户端提交。
