## 验证记录

使用 PyYAML 6.0.2，拒绝重复键；测试不调用手机或真实订阅，不执行下载的第三方 JavaScript。

```text
python proxy-configs/scripts/test-egern-audit.py --dependency-dir <PyYAML独立安装目录>
python proxy-configs/scripts/test-egern-audit.py --dependency-dir <PyYAML独立安装目录> --online
```

本次结果：10 个测试方法通过，包括 48 个美国节点名称样本、10 个内存负向变异、YAML/策略引用/本地规则顺序/URL 边界/模块去重/敏感域排除，以及对不可变基线重建的完整语义变更白名单。

在线检查：40 个启用配置直接引用资源 HTTP 200、非空且不是 HTML 页面；Maasea 模块含三条二进制钩子及全部参数占位符；两份上游 JS 通过 Node 语法检查；Google HTTPS 探针返回 204。部分资源需 Egern User-Agent。本次未递归验证其他所有模块的脚本依赖、图标、GeoIP 数据库或真实订阅。

注意：规则测试仅覆盖声明的本地语义与样本，不模拟完整 Egern 原生解析器、模块合并引擎或远程规则集。YAML 通过不等于手机端验收通过。远程模块/脚本仍有浮动分支依赖，本次不声称完成供应链锁定。

## 保留的风险与后续证据

- DNS：除移除公网 IP 查询外保持原值。`proxy_nameservers` 不是备用项，它会强制代理侧 DNS 使用国内上游并绕过 forward；这是可达性与隐私的取舍。Foreign-DoH 同组竞速，不能保证 NextDNS 每次参与过滤。缺少真实节点域名和解析日志，不能安全地改成强制境外 DNS。
- 模块：外加/缓存模块可能改变最终生效内容，更新主文件不证明重复钩子已经退出。12306 的排除是否覆盖模块注入要在有效配置中确认。高德、金融服务等其他模块扩展出的 MITM 范围仍需后续合并配置审查。
- 广告：单套主模块不代表所有 YouTube/微博版本广告都能去除。若仍有广告，需接口、广告位置、脚本日志和版本；不能只凭 MITM 图标诊断。历史 `googlevideo ... oad` 拒绝规则若与播放错误同时命中，应单独 A/B，不继续叠加更多规则。
- 稳定性：旧手动选组可能保留；地区池可能为空，必须查看实际订阅匹配结果。空组/全部节点失败的实际表现未验证。未启用全局“切换即关闭旧连接”，避免人为打断其他业务。
- 证书：未生成或改动 CA。若确实仍使用公共默认口令，先在 App 内核对证书管理方式，再按官方流程处理并备份；不要只改配置文本中的口令导致证书无法加载。

## 手机验收

1. 确认 Egern 为 2.20.0 或更新版本，更新原 `Egern_Pro_V26.00.yml`，文件头出现 `v6.5.1`。
2. 确认节点订阅未丢失；YouTube 选择 `YT-Auto` 且非空；Gemini 选择经过实际验证的美国节点池，不能依赖文件更新自动重置旧选择。
3. 在有效模块/脚本视图确认只有一套 YouTube、微博、ScriptHub 主处理；YouTube 三钩子已下载，上传屏蔽参数为 true；不重复导入第二份增强包。
4. 验证 12306 正常访问且不再 MITM。微信冷启动、消息、图片、语音/视频以及 Wi-Fi/蜂窝切换；微博检查正文图片与开屏/信息流广告。
5. YouTube 分别检查前贴/中插、PiP、后台、上传按钮和连续播放；至少 30 个视频及 3 次 60 分钟。记录故障发生时的策略、节点、请求及脚本错误，不把探针绿灯当成业务正常。
6. Gemini/ChatGPT 测登录、10 轮流式回复及附件；若失败，提供脱敏的 DNS、规则命中、实际出口及服务端错误，不上传 token、Cookie 或 CA 私钥。
7. 回归时只 revert 本次 Egern 提交并刷新；基线为 `6fcf24d`，不要 hard reset 或覆盖其他客户端的后续提交。
